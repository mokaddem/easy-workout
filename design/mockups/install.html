1. Première visite depuis le navigateur d’un téléphone ou d’une tablette

Affiché avant l’étape 1 de la configuration, sans barre d’onglets ni barre d’étapes. Les étapes portent l’écran. Du jaune seulement quand le navigateur propose vraiment d’installer ; sur iPhone, la sortie est un bouton contour, avec juste au-dessus la raison d’installer d’abord. Le sélecteur d’appareil marche : touche-le dans n’importe quel téléphone.

2. Depuis Réglages

Une ligne d’incitation en haut de Réglages, au-dessus de Ton entraînement, masquée quand l’app tourne installée. L’écran a un bouton retour et la barre d’onglets (il est sous Réglages, comme Données et sauvegarde), même contenu que l’accueil. Sur iPhone, il ajoute la ligne sur la configuration Safari et le chemin vers la sauvegarde.

3. Ordinateur (depuis Réglages seulement)

Les ordinateurs n’ont jamais l’écran d’accueil. La colonne de l’app garde la largeur d’un téléphone dans la fenêtre ; la barre de fenêtre est un décor de maquette, pour montrer où est l’icône de la barre d’adresse.

4. Pictos

Des pictos génériques dessinés sur la grille de 24 px de l’app, trait rond de 2 px : ils ressemblent à ce qu’on trouve dans le navigateur sans copier le dessin de personne. Dans les étapes, ils sont posés dans une petite touche (30 px dans les titres, 26 px dans les sous-lignes).
