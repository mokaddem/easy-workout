1. Onglet Séance rapide : Mes séances

Mes séances au-dessus du lanceur de séance rapide. Le lanceur garde le bouton principal du dock.

2. Détail d’une séance perso

Même mise en page que le détail de séance. Modifier dans la barre, le reste dans le menu d’options.

3. Éditeur

Un seul éditeur pour les séances du programme et les séances perso. Plein écran, sans barre d’onglets. Le compteur de durée reste épinglé sous la barre et roule à chaque changement.

4. Feuille de dose

Les changements s’appliquent en direct ; l’estimation est en haut de la feuille, le compteur étant sous le voile. Ni charge, ni objectif, ni tempo.

5. Choix de l’exercice

Plein écran dans le parcours de l’éditeur, pour laisser la place au clavier. Seulement les exercices que le matériel permet.

6. Détail d’une séance du programme

Modifier dans la barre sur chaque séance. Une séance modifiée le dit sous les chiffres ; une ligne modifiée remplace son pourquoi par ce qui a changé.

7. Résultat de séance rapide : enregistrer

Enregistrer dans la barre, pour que le dock garde Mélanger et Commencer.

8. Placer dans le programme

Choisir la séance remplacée ; le bouton principal nomme le résultat. La grille marque la case avec une lettre en pointillés.

9. Régénérer : ce que deviennent tes modifications

L’aperçu du nouveau programme gagne un bloc, juste sous ce qui reste. Seules les modifications qui ne s’appliquent plus sont listées ; les autres se replient.

10. Supprimer une séance placée dans le programme

La confirmation dit ce qui revient.
